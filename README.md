# AI-дайджест

Конверсионный сайт с кураторской подборкой курсов по искусственному интеллекту. Тёмный интерфейс, яркие акценты, необычные карточки и плавные анимации.

## Возможности

- 10 готовых карточек курсов из `content.json`
- Поиск по названию, описанию, платформе и тегам
- Фильтрация по тегам с подсчётом материалов
- Кликабельные теги внутри карточек
- Пустое состояние и сброс фильтров
- Кнопка «Открыть материал» с переходом на внешний курс
- Адаптивная вёрстка для телефона и компьютера
- Анимация появления, tilt-эффект карточек и движущийся фон
- Поддержка клавиши `/` для быстрого фокуса на поиске
- Уважение `prefers-reduced-motion` для пользователей, отключивших анимации

## Стек

- Python 3.10+
- Flask
- HTML, CSS, JavaScript
- JSON

## Структура проекта

```text
ai-course-site/
├── app.py                  # Flask-приложение и загрузка курсов
├── content.json            # данные карточек
├── requirements.txt        # зависимости Python
├── templates/
│   └── index.html          # HTML-шаблон страницы
└── static/
    ├── style.css           # оформление и адаптивность
    └── script.js           # поиск, фильтры и анимации
```

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Откройте в браузере: <http://127.0.0.1:5000>

Для Windows активация виртуального окружения:

```bash
.venv\Scripts\activate
```

## Как добавить карточку

Добавьте объект в массив `content.json`:

```json
{
  "title": "Название курса",
  "description": "Короткое описание: чему научитесь и для кого курс.",
  "link": "https://example.com/course",
  "tags": ["ML", "Python"],
  "source": "Платформа",
  "level": "С нуля",
  "duration": "≈ 10 часов"
}
```

| Поле | Обязательное | Назначение |
| --- | --- | --- |
| `title` | Да | Заголовок карточки |
| `description` | Да | Описание курса |
| `link` | Да | Ссылка на материал |
| `tags` | Да | Список тегов для фильтрации |
| `source` | Нет | Платформа или автор |
| `level` | Нет | Уровень сложности, показывается в карточке |
| `duration` | Нет | Примерная длительность курса |

Теги и количество материалов в фильтрах пересчитываются автоматически при запуске приложения.

## Логика работы

`app.py` читает `content.json` и передаёт курсы в шаблон `index.html`. Поиск и фильтрация выполняются в браузере в `script.js` — страница не перезагружается. Стили и анимации находятся в `static/style.css`.
